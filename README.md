## Overview

**Overall** is an AI-powered web analytics application that helps you understand website performance, analyze visitor behaviour, identify trends, and turn raw analytics into actionable intelligence.

Built to make web analytics more intuitive, insightful, and accessible.

## ✨ Features

- **AI-Powered Insights** — Turn complex analytics into understandable intelligence.
- **Traffic Analytics** — Understand website traffic and visitor activity.
- **Performance Monitoring** — Track important website metrics.
- **Data Visualization** — Explore information through clear visual representations.
- **Intelligent Analysis** — Discover patterns, trends, and opportunities.
- **Modern Dashboard** — Access your analytics through a clean, intuitive interface.

## Getting Started

```bash
# Clone the repository
git clone https://github.com/yatharth-real/overall-web-analytics

# Enter the project directory
cd overall

# Install dependencies
npm install

# Start development
npm run dev
```
